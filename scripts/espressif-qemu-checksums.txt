# sha256 of the pinned Espressif QEMU release assets, for scripts/install-sims.sh.
#
# Same reasoning as renode-checksums.txt: the installer used to ask GitHub for
# `releases/latest` and download whatever came back, so nothing in this
# repository governed the binary that ended up executing. An asset with no hash
# here stops the install rather than proceeding unverified.
#
# Measured 2026-08-03 by downloading each asset from the pinned release and
# hashing it with `shasum -a 256`, then cross-checking every line against the
# release's own published manifest,
# qemu-esp_develop_9.2.2_20260417-checksum.sha256, which agrees exactly. To bump
# the version: change QEMU_VERSION in install-sims.sh, download the new assets,
# hash them, and replace these lines. Never copy a hash from anywhere but a
# download you performed.
#
# Only the platforms install-sims.sh can install are listed. The Windows
# (x86_64-w64-mingw32) assets and the source tarball are deliberately absent:
# the script refuses to install what it has no hash for, and it does not serve
# Windows.
#
