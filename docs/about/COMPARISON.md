# Comparing Hauksbee with adjacent tools

Hauksbee combines several jobs that are commonly handled separately: reading
board and manufacturing artifacts, running static hardware checks, solving a
board-level electrical model, and coupling supported firmware emulators to that
model. It is not a replacement for the specialist tools below.

| Tool category | Primary authority | Use it for |
|---|---|---|
| CAD DRC/ERC | Native design database and rules | Geometry, clearance, and schematic-rule sign-off |
| SPICE simulator | Authored circuit deck and device models | Detailed analogue analysis and independent numerical comparison |
| MCU emulator | Firmware plus a modeled processor/platform | Instruction and peripheral behavior inside that backend |
| SI/PI extractor | Layout, stack-up, and field-solver model | Controlled-impedance, coupling, and power-integrity work |
| Hauksbee | Board/fab/assembly/firmware evidence supplied to a run | Cross-artifact checks and supported board-level co-simulation |

The overlap is deliberate: important Hauksbee findings should be reproduced in
the source CAD, an independent calculation or simulator, or on hardware before
a board change is made. The exact supported inputs and backend-specific proof
levels are maintained in [CAPABILITIES](CAPABILITIES.md) and
[LIMITATIONS](LIMITATIONS.md). Performance observations are generated by the
candidate-specific [speed gate](speed-gate-results.md) and are host-dependent.

When evaluating another product, verify its current vendor documentation. This
page does not claim that every edition, plugin, or hosted feature has been
exhaustively tested.
